  • Sum of All Subset XOR Totals

    • Total subsets: 每个元素有 Include / Exclude 两种选择，因此总共有 (2^n) 个 subsets。
    • Bit contribution: 对于任意一个 bit：
    • 如果所有元素在该 bit 上都是 0，那么所有 subset 的 XOR 在该 bit 上也都是 0。
    • 如果至少一个元素在该 bit 上是 1，那么恰好有一半的 subsets，其 XOR 在该 bit 上是 1。
    • OR operation: OR 会保留所有元素中出现过的 bit。因此，每个出现过的 bit 都会在 (2^{n-1}) 个 subset XOR 结果中出现。

    • Final result: 每个 bit 的贡献累加后，等于所有元素的 OR 结果乘以 (2^{n-1})。
      $$
      \boxed{
      \text{Sum of Subset XOR Totals}

      \left(\bigvee_{i=0}^{n-1} nums[i]\right)
      \times 2^{n-1}
      }
      $$

Sliding Window（滑动窗口）

Sliding Window 用于处理连续的 Subarray / Substring。

核心思想：维护一个窗口，通过移动左右指针，避免重复计算。

主要分为两种：

  • Fixed-size Window：固定窗口大小
  • Variable-size Window：可变窗口大小

1. Fixed-size Sliding Window

相关题目：LeetCode 643. Maximum Average Subarray I

题目目标： 找到长度为 k 的连续 Subarray，使其平均值最大。

核心思路

窗口大小固定为 k。

  1. 先计算第一个窗口的 Sum。
  2. 窗口向右移动一格。
  3. 减去离开窗口的元素。
  4. 加上新进入窗口的元素。
  5. 更新最大 Sum。

2. Variable-size Sliding Window

相关题目：LeetCode 3. Longest Substring Without Repeating Characters

题目目标： 找到最长的、不包含重复字符的连续 Substring。

核心思路

窗口大小不固定。使用两个指针：

  • left：窗口左边界。
  • right：窗口右边界。

使用 Set 记录当前窗口中的字符。

  1. right 不断向右移动，扩大窗口。
  2. 检查新字符是否已经存在于 Set。
  3. 如果存在重复字符，移动 left，并删除离开窗口的字符。
  4. 直到窗口重新满足条件。
  5. 将新字符加入 Set。
  6. 更新最大长度。

指针理解

  • right：负责扩大窗口。
  • left：窗口不满足条件时，负责缩小窗口。
  • Set：始终记录当前窗口中的字符。

Graph Traversal

Graph Traversal is the process of visiting nodes (vertices) in a graph to find paths, check connectivity, or explore connected components.

相关题目：LeetCode 1971. Find if Path Exists in Graph

Graph Representation

Adjacency List（邻接表）

An Adjacency List stores all neighbors of each node.

Convert Edge List into Adjacency List:

  • Key: current node.
  • Value: all neighbors connected to that node.
  • Undirected Graph: add both directions.
  • Directed Graph: only add the directed edge.

DFS（深度优先搜索）

DFS explores one path as deeply as possible before backtracking to explore other paths.

  • Recursive DFS
    Uses the function call stack to manage the traversal.
  • Iterative DFS
    Uses an explicit Stack instead of recursive function calls.

BFS（广度优先搜索 Breadth-First Search）

BFS explores all neighbors at the current level before moving to the next level.
Uses a Queue (FIFO) to manage the traversal.

DFS vs BFS

Feature DFS BFS 说明
Data Structure Stack (LIFO) Queue (FIFO)
Traversal Order Deep first Level by level
Time Complexity O(V + E) O(V + E) E = Number of edges
Space Complexity O(V) O(V) V = Number of vertices (nodes)
Recursive Version Yes Possible, but uncommon
Iterative Version Yes Yes
Shortest Path Not guaranteed Guaranteed (for unweighted graphs)
Cycle Detection Use visited Use visited
